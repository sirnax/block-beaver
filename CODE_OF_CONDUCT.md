# Code of conduct

We want Block Beaver discussions and contributions to be respectful and useful to people with different backgrounds and levels of experience.

## Expected behavior

- Be considerate and direct. Critique code and ideas rather than people.
- Give others room to ask questions and correct mistakes.
- Respect privacy. Do not publish private messages, source code, or personal information without permission.

Harassment, threats, discriminatory language, and sustained disruption are not acceptable in project spaces. Maintainers may edit or remove comments, close discussions, or restrict participation when needed.

Report conduct concerns privately to the maintainer through the contact method on their GitHub profile. For abuse on GitHub, use GitHub's **Report content** feature. Include relevant links and context; the maintainer will review the report and respond as appropriate. Do not file a public issue about another person's conduct.
